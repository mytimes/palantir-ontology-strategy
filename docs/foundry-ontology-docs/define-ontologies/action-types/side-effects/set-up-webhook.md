# 设置 Webhook（Set up a webhook）

> 本文为 [Palantir 官方文档](https://www.palantir.com/docs/foundry/action-types/set-up-webhook/)的非官方中文翻译，仅供学习参考。原文 © 2026 Palantir Technologies Inc. 保留所有权利。

## 前提条件

1. 完成[入门](https://www.palantir.com/docs/foundry/action-types/getting-started/)教程，了解如何设置基本动作。
2. 设置一个 [Webhook](https://www.palantir.com/docs/foundry/data-connection/webhooks-setup/) 以创建到外部系统的连接。在创建 Webhook 之前，你可能需要与有权连接源系统的系统管理员协作。

## 步骤

在下面的示例中，假设我们有一个名为 **Modify ticket priority**（修改工单优先级）的 Webhook，它接受一个 `priority` 字符串值并将其发送到外部系统。

导航到你的动作，选择 **Logic（逻辑）** 标签页，选择 **Add new rule（添加新规则）**，然后选择 **Webhook**。

![添加新 Webhook](https://www.palantir.com/docs/resources/foundry/action-types/webhooks-add-new-rule-webhook.png?width=600)

默认情况下，新添加的 Webhook 被配置为**副作用**；这会使 Webhook 在 Foundry 中的对象被编辑*之后*运行。或者，选择 **Writeback（回写）** 可使 Webhook 在对象编辑*之前*运行。

![选择回写或副作用](https://www.palantir.com/docs/resources/foundry/action-types/webhooks-select-writeback-or-side-effect.png?width=400)

在下面的菜单中，选择你要执行的 Webhook。在本示例中，我们选择 **Modify ticket priority** Webhook。如果愿意，你可以选择该 Webhook 的不同版本。

![选择要执行的 Webhook](https://www.palantir.com/docs/resources/foundry/action-types/webhooks-select-webhook-to-execute.png?width=400)

接下来，基于动作参数配置 Webhook 输入参数。默认情况下，每个 Webhook 输入都会生成一个新的动作参数，除非已存在同名的动作参数，此时会自动配置现有参数。在本示例中，我们将名为 `priority` 的 Webhook 输入映射到名为 `Ticket Priority`（工单优先级）的现有动作参数。

![将 Webhook 输入映射到现有动作参数](https://www.palantir.com/docs/resources/foundry/action-types/webhooks-input-mapping-example.png?width=400)

选择 **Add webhook（添加 Webhook）** 完成向动作添加 Webhook 规则。请注意，添加 Webhook 后，Rules（规则）部分会显示回写将在对象被修改之前发生。

![添加新 Webhook（已完成）](https://www.palantir.com/docs/resources/foundry/action-types/webhooks-add-webhook-complete.png?width=600)

你可能希望删除添加 Webhook 时自动生成的、现在已不再使用的任何参数。

![删除自动生成的参数](https://www.palantir.com/docs/resources/foundry/action-types/webhooks-remove-autogenerated-parameters.png?width=600)

选择右上角的 **Save（保存）** 以保存对动作的更改。现在，当动作被应用时，对外部系统的请求将在 Foundry 中的对象发生任何更改之前发出。
