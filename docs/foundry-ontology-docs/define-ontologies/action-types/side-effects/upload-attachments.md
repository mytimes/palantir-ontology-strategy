# 上传附件（Upload attachments）

> 本文为 [Palantir 官方文档](https://www.palantir.com/docs/foundry/action-types/upload-attachments/)的非官方中文翻译，仅供学习参考。原文 © 2026 Palantir Technologies Inc. 保留所有权利。

动作支持从 Workshop、Object Explorer、Object Views、Quiver 和 Slate 上传附件。查看、编辑和删除附件的权限与附件所上传到的对象一致。例如，如果用户对某个对象拥有查看权限，他们将能够查看和下载存储在该对象上的附件。替换现有附件则需要对该对象拥有编辑权限。

你可以上传单个附件或附件列表。要使用动作上传附件，请同时遵循动作类型和对象类型的配置步骤。

## 配置动作类型

在参数配置视图中，选择 **Attachment（附件）** 作为参数类型。附件只能使用附件参数类型上传。对象支撑数据集中对应的列必须是 **String**（字符串）类型，且被编辑的对象属性必须是 **Attachment**（附件）类型。

要一次上传多个媒体文件，请选择 **Allow multiple values（允许多个值）**。请注意，在一个动作中支持多个媒体文件，还需要在[对象类型配置](#配置对象类型)期间额外打开 **Allow multiple（允许多个）** 开关，如下所述。

## 配置对象类型

在对象详情视图中，选择 **Attachment（附件）** 作为属性类型。附件只能上传到附件属性类型。

要向一个属性上传多个媒体文件，请打开 **Allow multiple（允许多个）** 开关。在这种情况下，对象支撑数据集中的该属性必须是 **Array**（数组）类型。

## 架构与限制

附件一旦被添加到动作表单，就会立即上传到 Foundry。表单提交时，查看、编辑和删除附件的权限根据用户对底层对象类型的权限推断得出。如果表单提交失败或被取消，已上传的附件将不再可直接访问，并会在一段时间后自动永久删除。同样，属于已删除对象的附件，或不再映射到对象的附件（当相应属性被删除时会发生这种情况），将不再可直接访问，并最终会自动永久删除。

逻辑支撑和函数支撑的动作都支持附件。全局固定的文件大小限制为 200MB。

- 每个附件在其生命周期内最多可以链接到十个对象。如果一个附件已链接到十个对象，即使最初链接的对象中有一个或多个已被删除，它也无法再链接到任何其他对象。达到十个链接对象的上限后，你可以将该文件作为新附件重新上传，以将其链接到更多对象。
