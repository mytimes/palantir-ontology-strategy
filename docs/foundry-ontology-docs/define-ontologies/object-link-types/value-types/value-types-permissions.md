# 值类型权限（Value type permissions）

> 本文为 [Palantir 官方文档](https://www.palantir.com/docs/foundry/object-link-types/value-types-permissions/)的非官方中文翻译，仅供学习参考。原文 © 2026 Palantir Technologies Inc. 保留所有权利。

值类型的权限通过平台[空间](https://www.palantir.com/docs/foundry/platform-security-management/manage-orgs-and-spaces/#spaces)管理。空间中的任何值类型都会自动导入并提供给关联的本体使用。其他使用者可以将值类型导入到他们的项目范围内，这类似于用户可以导入转换配置文件或管道输入的方式。

对空间拥有查看（读）权限的用户可以在该空间及关联本体中将值类型分配给属性类型或共享属性类型。空间的编辑者（Editor）或所有者（Owner）可以在该空间中创建、编辑或删除值类型。
