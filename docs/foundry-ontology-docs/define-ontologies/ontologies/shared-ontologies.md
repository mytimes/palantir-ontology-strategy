# 共享本体（Shared ontologies）

> 本文为 [Palantir 官方文档](https://www.palantir.com/docs/foundry/ontologies/shared-ontologies/)的非官方中文翻译，仅供学习参考。原文 © 2026 Palantir Technologies Inc. 保留所有权利。

共享本体是一种特殊的本体，它允许多个[组织](https://www.palantir.com/docs/foundry/security/orgs-and-spaces/#organizations)在共享工作流上协作。共享本体位于专门为该工作流创建的共享[空间](https://www.palantir.com/docs/foundry/security/orgs-and-spaces/#spaces)之下。共享本体使来自多个组织的资源能够在同一个工作流中使用；而普通本体是某个组织私有的，仅包含该组织自己的资源。

创建新的共享空间时，会自动创建一个共享本体。它带有与该共享空间相同的组织[标记](https://www.palantir.com/docs/foundry/security/markings/)和[角色授权](https://www.palantir.com/docs/foundry/security/projects-and-roles/#roles)。

为了帮助你判断某个工作流需要共享本体还是私有本体，请参阅[私有本体与共享本体的对比示例](https://www.palantir.com/docs/foundry/ontologies/ontologies-overview/#private-vs-shared-ontologies)。

有关如何建立安全协作工作流的更多详情，请参阅[跨组织协作](https://www.palantir.com/docs/foundry/security/cross-organization-collaboration/)。
