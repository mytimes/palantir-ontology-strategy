# 编辑接口实现（Edit an interface implementation）

> 本文为 [Palantir 官方文档](https://www.palantir.com/docs/foundry/interfaces/edit-interface-implementation/)的非官方中文翻译，仅供学习参考。原文 © 2026 Palantir Technologies Inc. 保留所有权利。

接口一旦在对象上实现，你就可以通过删除实现或更改映射来更新实现。

首先，打开 Ontology Manager，导航到你要编辑其接口实现的对象。

## 1. 删除接口实现

选择 **...** 图标并选择 **Remove interface**（移除接口），以从该对象类型删除接口的实现。

![移除接口实现。](https://www.palantir.com/docs/resources/foundry/interfaces/remove-interface-implementation.png?width=800)

选择右上角的 **Save**（保存）以更新本体。

## 更新实现映射

选择下拉菜单以更新用于实现接口的属性或链接类型。

![更新接口实现映射](https://www.palantir.com/docs/resources/foundry/interfaces/update-interface-implementation-mapping.png?width=800)

选择右上角的 **Save**（保存）以更新本体。
